# Habits For Practica

This is a distilled operating memo from Atomic Habits ideas, rewritten for Practica.
It is not a transcript and it does not include timestamps.

## The Core Lesson

- outcomes follow systems
- habits beat goals when you want repeated wins
- the product should make the first useful action easy
- the product should make progress visible and satisfying

## Practical Rules

1. Make it easy to start.
2. Reduce the scope, but keep the schedule.
3. Design for the first five minutes.
4. Prime the environment so the right action is obvious.
5. Use tiny steps that are embarrassingly small if needed.
6. Make the behavior fun or at least more fun than the default.
7. Keep the user from throwing up a zero.
8. Let the user recover fast after a miss.
9. Stack new actions on top of existing routines.
10. Review and reflection are part of the system.

## What This Means For Practica

- Practica should help a person do one small action today, not plan a huge transformation.
- The main job is to reduce friction between intention and action.
- Every screen should answer: can the user start now?
- Every reward should be immediate enough to keep the loop alive.
- Every habit should feel easy to return to after a bad day.
- Every feature should help the user continue the system, not just chase an outcome.
- The app should feel like a game: proof, points, streak, level, repeat.

## Product Manager Lens

Use these questions when deciding what to build:

- does this make the first action easier?
- does this make the good habit more obvious?
- does this make the habit more attractive or fun?
- does this make completion feel satisfying?
- does this reduce decision fatigue?
- does this help the user stay on track after a miss?
- does this fit the way the user wants to spend their days?

If the answer is no, the feature is probably decoration.

## Practica Application

For Practica, the habit loop should feel like:

1. open the app
2. see one clear next action
3. record or check in quickly
4. get proof, reward, or progress feedback
5. come back tomorrow

That is the product. Everything else should support it.
